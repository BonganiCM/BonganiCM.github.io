Web App Hacking V8, Day 1

The opening day focused on how to think before testing an application. I worked through introductory modules, studied modern web stack diagrams and started the practical lab environment.

How a tester reasons

  1. Understand the concept
  2. Map the architecture
  3. Establish normal behaviour
  4. Identify trust boundaries
  5. Assess for vulnerabilities

Anatomy of a modern web application

  1. Browser
  2. CDN
  3. Web application firewall
  4. Reverse proxy or load balancer
  5. API gateway
  6. Microservices
  7. Databases and caches

Each connection in the architecture represents a trust boundary. Understanding those boundaries gives a tester a sound map of the application before any testing begins.

Lab notes/Network security

CWE Fully Compromised Network Lab

A multi-host penetration test run as one complete attack chain. The lab focused on gaining initial access, enumerating hosts, analysing vulnerabilities, then moving laterally and escalating privileges across several systems.

  • Network penetration testing
  • Controlled lab
  • Pivoting

Assessment workflow

Attack path

  1. Initial access
  2. Enumeration
  3. Vulnerability analysis
  4. Lateral movement
  5. Privilege escalation
  6. Pivoting with Chisel and Socat
  7. Access to internal services, including Grafana dashboards

Tooling

Tools and techniques

Chisel

Tunnelled traffic over HTTP to reach internal network segments.

Socat

Relayed sockets and forwarded ports between hosts.

Lab context

This was a controlled training environment. The exercise brought host-level discovery, analysis and network pivoting together into a single assessment workflow.
